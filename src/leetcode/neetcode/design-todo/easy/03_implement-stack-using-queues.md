# Implement Stack Using Queues

[LeetCode #225](https://leetcode.com/problems/implement-stack-using-queues/description/)

---

### Statement

Implement a **LIFO stack** using only two **FIFO queues**. The implemented stack must support all functions of a normal stack.

Implement `MyStack`:
- `void push(int x)` — pushes element `x` to the top.
- `int pop()` — removes and returns the top element.
- `int top()` — returns the top element without removing it.
- `boolean empty()` — returns `true` if the stack is empty.

**Constraints:**
- \\( 1 \le x \le 9 \\)
- At most `100` calls to `push`, `pop`, `top`, and `empty`.
- All `pop` and `top` calls are on a non-empty stack.

### Examples

**Example 1:**
```text
Input:  ["MyStack","push","push","top","pop","empty"]
        [[],[1],[2],[],[],[]]
Output: [null,null,null,2,2,false]
```
