# Design HashMap

[LeetCode #706](https://leetcode.com/problems/design-hashmap/description/)

---

### Statement

Design a HashMap **without** using built-in hash table libraries.

Implement `MyHashMap`:
- `MyHashMap()` — initializes an empty map.
- `void put(int key, int value)` — inserts or updates the mapping for `key`.
- `int get(int key)` — returns the value for `key`, or `-1` if not found.
- `void remove(int key)` — removes `key` if present.

**Constraints:**
- \\( 0 \le \text{key}, \text{value} \le 10^6 \\)
- At most \\( 10^4 \\) calls to `put`, `get`, and `remove`.

### Examples

**Example 1:**
```text
Input:  ["MyHashMap","put","put","get","get","put","get","remove","get"]
        [[],[1,1],[2,2],[1],[3],[2,1],[2],[2],[2]]
Output: [null,null,null,1,-1,null,1,null,-1]
```
